# El amor hacia la persona que me lo enseñó

Libro digital interactivo para Itza.

## Publicar con GitHub Pages

En el repositorio, abre **Settings → Pages**. En **Build and deployment**, selecciona **Deploy from a branch**, elige la rama **main** y la carpeta **/(root)**, y pulsa **Save**.

Cuando termine la publicación, el libro estará disponible en:

https://migxe.github.io/libro-para-itza/
